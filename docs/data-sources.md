# 数据来源

本文列出系统实际访问的数据源、用途、失败模式与扩展方式。
合规与免责条款见 [../DISCLAIMER.md](../DISCLAIMER.md)。

## 一、来源清单

| 来源 | 用途 | 入口 | 失败时会怎样 |
|---|---|---|---|
| 巨潮资讯 | 实体解析（代码 / orgId / 全称）、公告列表、公告 PDF | `infra/sources/cninfo.py` | 实体解析失败则整次运行失败并提示；公告失败则该路材料为空，记入缺口 |
| 东方财富 | 公司档案、主营构成、定期报告指标、资讯检索 | `infra/sources/eastmoney.py` | 档案缺失时用巨潮字段兜底；指标取不到则专题不出点；资讯为空只减少覆盖 |
| 工业和信息化部 | 产业政策、专项资金等公告 | `services/govpolicy.py` | 检索失败时返回空结果与原因，不编造条目 |
| 省级工信主管部门（31 个） | 地方政策与补贴公告 | `services/govpolicy.py` 的 `PROVINCE_SITES` | 站点不可达记入 `data/prov_health.json`，页面提示「已知取不到」 |
| 用户上传材料 | 政策文件（pdf / docx / txt / md / html） | `services/policy.py` | 单份失败只影响该份，进异常清单；扫描件因无文本层判失败 |

## 二、调用约定

- 所有请求经 `core/net.py`：统一超时、有限重试、同域最小间隔（`host_interval`，默认 0.45 秒）。
- 不包含验证码识别、登录态伪造、代理轮换等绕过访问控制的手段。
- 请求失败按「单份失败不阻断整批」处理：记原因、保留链接、继续下一份。
- 抓取结果落 `documents` 表并标注证据等级：
  - `full`：拿到正文（公告 PDF 文本层或资讯正文）
  - `snippet` / `title`：只有摘要或标题（图片型 PDF、正文抓取失败）
- 原文只用于本地解析与引用，报告与导出中保留原始 URL。

## 三、省级站点健康

- `PROVINCE_SITES` 收录 31 个省级工信主管部门站点，`CITY_PROV` 负责城市到省份的归一。
- 每次取数后记录该省最近一次可用性到 `data/prov_health.json`。
- 实测常有 1—3 个站点不可达（近期为甘肃、海南、安徽），属于上游波动，不是程序缺陷。
- 页面与日志会区分两种「没有结果」：
  - **站点不可达**：网络层失败，建议稍后重试或人工补材料
  - **确实没有相关政策**：站点可达但没有匹配条目
- 部分省份的政策专栏为 JS 渲染，列表页拿不到正文时需人工放入 `materials/`。

## 四、新增一个数据源

1. 在 `infra/sources/` 新建模块，只做两件事：请求与归一化。
2. 输出统一的文档形状：

```python
{
    "id": "D01",                 # 本次运行内唯一
    "kind": "announcement",      # announcement / news / web
    "title": "...",
    "url": "https://...",        # 必须保留，供回溯
    "source": "巨潮资讯",
    "published_at": "2026-11-20",
    "body": "...",               # 可为空，空则证据等级降级
    "evidence_level": "full",    # full / snippet / title
}
```

3. 不要在这里做事件分类、置信度或判断——这些属于 `services/`。
4. 失败要能降级：返回空列表并说明原因，不要向上抛异常打断整批。
5. 在 `tools/selftest_all.py` 里为归一化逻辑加断言（可用固定样本，不联网）。

## 五、与数据源相关的配置

| 配置 | 默认 | 作用 |
|---|---|---|
| `days` | 30 | 公告与资讯回溯天数 |
| `max_ann` / `max_news` | 40 / 45 | 每路材料条数上限 |
| `max_fetch` | 12 | 正文抓取条数上限，控制耗时 |
| `news_pages` | 3 | 资讯翻页数 |
| `timeout` / `retries` | 15s / 2 | 单请求超时与重试 |
| `host_interval` | 0.45s | 同域最小请求间隔 |

环境变量前缀 `MINGJIAN_`，旧 `AGENT_` 前缀兼容。完整清单见 `config.example.json`。
